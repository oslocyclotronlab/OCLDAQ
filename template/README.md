# Templates

This directory contains template configuration files and scripts used for setting up the DAQ system.

## Contents

- `settings.set`: Default system settings.
- `setup.yml`: YAML configuration for system setup.
- `pxisys.ini`: PXI system configuration.
- `XIA_Firmware.txt`: Template for XIA firmware configuration.
- `acq_master_commands.txt`: List of commands for the acquisition master.
- `input.sh` / `output.sh`: Helper scripts for input/output operations.
